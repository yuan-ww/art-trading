# 数据库

公开仓库不包含生产或历史数据导出。运行项目需要一个名为 `user_auth` 的 MySQL 数据库，并在 `demo/.env` 中配置连接信息。

本地历史数据导出位于项目目录外的 `../数据库/DataBase.sql`，仅应在受控的本地环境中使用。后续应补充不含个人数据的 schema 与测试数据，供 CI 使用。

`migrations/001-integrity-constraints.sql` 为可重复执行的完整性约束迁移：它先列出需要人工处理的重复数据，再为收藏、拍卖报名、物流和评价添加唯一约束。该脚本不会由应用自动执行；请先备份并在测试数据库验证后再手动运行。

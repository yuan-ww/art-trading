# 项目结构

```text
ArtTrading 2/
├── demo/       Spring Boot 3 后端
│   ├── src/main/java/     控制器、服务、实体、仓储与配置
│   └── src/main/resources/ 静态资源与环境配置
├── front/      Vue 3 前端
│   └── src/               页面、组件、路由、状态与 API 服务
├── scripts/    本地启动脚本
├── docs/       项目说明
└── database/   数据库初始化说明（不存放真实数据）
```

后端默认监听 `10202`，前端开发服务器默认监听 `8080`。前端接口根地址由 `VUE_APP_API_BASE_URL` 控制；后端数据库、上传目录与 CORS 来源由 `demo/.env` 控制。

## 业务模块

- 用户与个人资料
- 艺术品、分类、图片与轮播
- 拍卖、出价与报名
- 订单、物流、收藏与评价

## 当前边界

数据库导出文件不纳入公开仓库，以避免公开历史用户与业务数据。需要可公开复现的环境时，应提供单独的脱敏 schema 与测试数据。
